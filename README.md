# 調布の教習予約 自動予約プログラム

教習の空き枠を24時間監視します。予約対象が「高速AT1」から次の教習へ変わっても、同じシステムが監視を継続します。

## 予約ルール

- **翌日以降の空き**：その場で自動予約し、完了後にiPhoneへ通知
- **当日分の空き**：予約せずiPhoneへ通知し、通知から承認した場合だけ予約
- 承認後に枠が埋まっていた場合：予約せず、その旨を通知
- 予約対象が変わった場合：変更を通知して監視継続

当日分の通知にある「内容を確認して承認」を開くと、教習内容と日時、キャンセル料の注意が表示されます。そこで承認ボタンを押した場合のみ、空きを再確認して予約します。承認リンクは初期設定で5分間・一度だけ有効です。

## 安全機能

- 当日予約は承認前に実行しない
- 当日の承認リンクを推測困難な一時トークンで保護
- メンテナンス表示中は予約操作を行わず、5分後に自動再確認
- ログイン情報をソースコードへ保存しない
- 予約確認ボタンを安全に特定できない場合は、予約せずエラー通知
- 約70〜80秒の間隔で確認し、サイトへ過度な負荷をかけない

## 1. iPhone通知を準備

1. iPhoneに **ntfy** アプリをインストールします。
2. アプリで、他人に推測されにくい長いトピック名を1つ購読します。
   - 例：`chofu-driving-` にランダムな英数字を20文字以上追加
3. そのトピック名を、後述の `NTFY_TOPIC` に設定します。

トピック名を知っている人は通知を読み書きできるため、氏名・教習生番号・パスワードはトピック名に含めないでください。

## 2. 無料クラウドへ配置（RenderのFree Web Service）

当日予約の承認画面を開くため、公開URLを持つRenderのFree Web Serviceを使用します。無料サービスは15分間アクセスがないと停止するため、同梱のGitHub Actionsが10分ごとにヘルスチェックを行います。

1. このフォルダを公開GitHubリポジトリへアップロードします。公開するのはプログラムだけで、ログイン情報や通知トピックはGitHub SecretsとRenderの非公開環境変数に保存します。
2. Renderで **New → Blueprint** を選び、リポジトリを接続します。
3. 次のEnvironment VariablesをRenderの画面で入力します。

| 変数 | 設定内容 |
|---|---|
| `START_URL` | 教習予約サイトのURL全体 |
| `STUDENT_ID` | 教習生番号 |
| `PASSWORD` | パスワード |
| `NTFY_TOPIC` | iPhoneで購読した長いトピック名 |
| `AUTO_BOOK` | 最初は `false` |
| `POLL_INTERVAL_SECONDS` | `70` |
| `APPROVAL_MINUTES` | `5` |
| `SAME_DAY_RENOTIFY_MINUTES` | `10` |
| `MAINTENANCE_RETRY_MINUTES` | `5` |

ログイン情報はGitHubや`.env`へ書かず、クラウドのSecret / Environment Variableとして保存してください。

デプロイ後、GitHubリポジトリの **Settings → Secrets and variables → Actions** に次を登録します。

| Secret | 設定内容 |
|---|---|
| `SERVICE_URL` | Renderが発行した公開URL（末尾の `/` は不要） |

`.github/workflows/keep-awake.yml` が10分ごとに `/healthz` を呼び、無料サービスのスリープを防ぎます。

## 3. 試運転して本番へ切り替え

1. `AUTO_BOOK=false` で起動します。
2. iPhoneに「教習予約の監視を開始しました」と届くことを確認します。
3. Renderのログにエラーがないことを確認します。
4. `AUTO_BOOK=true` に変更し、再デプロイします。

以後、翌日以降の空きは自動予約します。当日分だけは通知から承認した場合に限って予約します。完了通知を受け取ったら、念のため予約サイトの「予約一覧」でも確認してください。

## ローカルでの確認（任意）

```bash
cp .env.example .env
# .envを編集した後
docker build -t chofu-auto-booker .
docker run --rm --env-file .env chofu-auto-booker
```

## 注意

- 教習所の利用規約で自動アクセスが禁止されている場合は使用しないでください。
- 監視間隔を60秒未満にしないでください。
- RenderやGitHubの無料枠・仕様が変更された場合、構成の見直しが必要です。
- サイトの画面仕様が変更された場合は、安全のため予約せずエラー通知を出します。
- メンテナンス表示中はログインや予約操作を行わず、終了後に自動復帰します。
- URLやログイン情報を第三者へ共有しないでください。
